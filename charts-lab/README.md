# Лаборатория графиков

[Открыть стенд](https://pavelpotapov.github.io/testCharts/) · [Исследование и проект API](RESEARCH.md)

Семь видов на Recharts 3.11.0. На вкладке лаборатории меняйте параметры и переключайтесь между кодом текущей конфигурации и таблицей исходных данных. Подсказку линии можно открыть наведением или фокусом на графике и клавишами со стрелками. Код адаптера доступен рядом с примером использования.

## Сценарии на стенде

- **Линия.** В светлой и тёмной темах `RechartsThemeProvider` задаёт палитру, фон, сетку, оси и текст. Цвет «Факт» можно переопределить через `Line.stroke`. Цвет «План» при этом берётся из темы.
- **Легенда и подсказка.** `Legend.verticalAlign` меняет положение легенды внутри графика. `Tooltip.formatter` добавляет единицы к значениям, а `Tooltip.content` выводит собственную разметку с отклонением от плана. При отсутствии факта подсказка показывает статус расчёта.
- **Граничные данные.** Пропуск в июне демонстрирует `connectNulls` у линии. В столбцах `stackOffset="sign"` разделяет положительные и отрицательные значения, `ReferenceLine` показывает ноль, `BarStack.radius` скругляет общий контур. Нулевая сумма секторов даёт пустое состояние.
- **Движение.** Кнопка повтора заново монтирует график и проигрывает появление линии. Переключатель периода обновляет график на месте, сохраняя идентичность общих точек по `matchByDataKey('id')`. Движок интерполирует их координаты. Для собственного способа интерполяции, например управляемой траектории движения точки, у `Line` есть `animationInterpolateFn`. Режим `auto` учитывает системную настройку сокращения движения.

## Локальный запуск

Из каталога `charts-lab` с Node.js 22 и pnpm 10.30.3:

```sh
pnpm install --frozen-lockfile
pnpm dev
```

`pnpm build` компилирует ESM-входы и объявления TypeScript в `lib`, проверяет потребителя и собирает стенд в `dist`. При изменении исходников обёрток повторите `pnpm build:lib`. Относительные URL ассетов работают под путём репозитория на Pages.

## Импорт одного вида

```tsx
import { LineChart } from '@chart-lab/charts/line';

export function Revenue() {
  return <LineChart
    title="Продажи, млн ₽"
    data={[{ month: 'Янв', sales: 21 }, { month: 'Фев', sales: 28 }]}
    categoryKey="month"
    series={[{ key: 'sales', label: 'Продажи', color: '#147d72' }]}
    strokeWidth={3}
  />;
}
```

`@chart-lab/charts` — локальное имя приватного пакета прототипа. Семь подмаршрутов в `exports` ссылаются на независимо скомпилированные ESM-модули. Общее оформление лежит в `charts/shared.tsx`. Страница использует реальные подмаршруты и загружает выбранный вид через `React.lazy`. Реактивные настройки и данные принадлежат стенду. npm-публикация или изменение UI-кита для запуска не требуются.

## Проверка веса

`pnpm measure` собирает девять минимальных потребителей через Vite 6.4.1 и обновляет [`src/sizes.json`](src/sizes.json). В контрольный пример входит React 18.3.1 с React DOM. Остальные используют тот же код монтирования и один или семь подмаршрутов. Скрипт проверяет список оставшихся адаптеров по отрендеренным модулям Rollup и записывает модули каталога Recharts `chart/`. gzip считается отдельно для каждого JS-чанка. Вкладка «Размер импорта» читает результаты.

React с React DOM занимает 45 539 байт gzip, потребитель с линией — 172 682 байта, потребитель со всеми входами — 210 526 байт. В этой сборке линия добавляет 127 143 байта к React, разница между линией и всеми входами составляет 37 844 байт. Стоимость линии выросла на 3 901 байт после добавления темы, легенды и подсказок. Суммарный прирост всех входов составил 6 109 байта с учётом проверки пустых секторов и стека со смешанными знаками.

## Публикация

Workflow GitHub Pages устанавливает зависимости по локальному lock-файлу, повторяет измерение и сборку и публикует только `charts-lab/dist`. Исторические проекты сравнения находятся в соседних каталогах.
