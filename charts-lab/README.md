# Лаборатория графиков

[Открыть стенд](https://pavelpotapov.github.io/testCharts/) · [Исследование и проект API](RESEARCH.md)

Стенд открывается на витрине с десятью видами на Recharts 3.11.0. Кнопка «Настроить» переносит выбранный график в лабораторию. Лаборатория запоминает настройки каждого вида в браузере и восстанавливает их после перезагрузки. Тема общая для всего стенда, кнопка «Сбросить» действует на выбранный график. Под графиком доступны код обёртки, исходные данные и редактор Recharts с отдельным предпросмотром. Подсказку линии можно открыть наведением или фокусом на графике и клавишами со стрелками. Код адаптера доступен рядом с примером использования.

## Сценарии на стенде

- **Линия.** В светлой и тёмной темах `RechartsThemeProvider` задаёт палитру, фон, сетку, оси и текст. Цвет «Факт» можно переопределить через `Line.stroke`. У «Плана» свой токен и свой выбор цвета.
- **Легенда и подсказка.** У всех десяти обёрток `legendPosition` размещает легенду сверху, снизу, слева или справа. Если опустить параметр, легенда скрыта. Общий компонент `Tooltip.content` выводит цветную точку, имя и значение каждой видимой серии. У линии доступны единицы и отклонение от плана. У столбцов `Tooltip.cursor` задаёт мягкую заливку всей категории. При отсутствии факта подсказка показывает статус расчёта.
- **Граничные данные.** Пропуск в июне демонстрирует `connectNulls` у линии. В столбцах `stackOffset="sign"` разделяет положительные и отрицательные значения, `ReferenceLine` показывает ноль, `BarStack.radius` скругляет общий контур. Нулевая сумма секторов даёт пустое состояние.
- **Движение.** Кнопка повтора заново монтирует график и проигрывает появление линии. Переключатель периода обновляет график на месте, сохраняя идентичность общих точек по `matchByDataKey('id')`. Движок интерполирует их координаты. Для собственного способа интерполяции, например управляемой траектории движения точки, у `Line` есть `animationInterpolateFn`. Режим `auto` учитывает системную настройку сокращения движения.

## Что проверить в лаборатории

- В «Секторах» выберите «Геометрия» и увеличьте скругление углов. Зазор между долями и радиус отверстия меняются отдельно. В «Области» сравните постоянные точки с активными, включите градиент и посмотрите, как выглядит пропуск в июне.
- В «Редакторе Recharts» можно подставить собственные данные, добавить вторую ось, порог или другую серию. Справочник имён свойств строится из типов установленной версии командой `node scripts/chart-api.mjs`. Свой React-шаблон или функцию форматирования подключают из кода приложения.
- В «Линии» выберите короткий штрих и полые точки. Контур маркера остаётся сплошным при любом штрихе линии. Выберите круг, ромб, квадрат или треугольник. Для наведения доступны мгновенный показ, увеличение, проявление и однократный пульс. Подсказку можно закрепить в углу, включить проявление или сдвиг снизу и подобрать длительность. Радиусы обычного и активного маркеров задаются отдельно. Нулевой активный радиус отключает выделение точки.
- Переключатели «Факт» и «План» в декартовых графиках и радаре меняют состав видимых серий и подсказки. При одном выбранном ряде его цвет сохраняется.
- «Линия и столбцы» накладывает план на факт в одной шкале. «Радиальные полосы» показывают прогресс каналов по шкале 0–100. «Воронка» позволяет менять направление, подписи и форму последнего этапа.
- В «Возможностях» для каждого вида указаны модель данных, настройки Recharts, визуальный эффект и границы применения. Кнопка открывает выбранный вид в лаборатории.

## Передача настройки

Над графиком в лаборатории три кнопки. «Скопировать настройку вида» кладёт в буфер обмена JSON выбранного вида, «Скопировать все виды» собирает в один JSON все виды, где что-то изменено. В JSON попадают только параметры, которые отличаются от начальных значений вида, поэтому видно, что именно выбрал дизайнер. «Вставить настройку» принимает такой JSON или только его блок `views` и применяет его. Лаборатория пропускает неизвестные виды и недопустимые значения и перечисляет их в строке состояния. Вид с принятой настройкой восстанавливается из исходных значений и переданных параметров. Виды, которых нет в файле, сохраняют свои настройки. Если в файле есть только тема, она применяется ко всей лаборатории.

```json
{
  "format": "chart-lab/settings@1",
  "recharts": "3.11.0",
  "theme": "light",
  "views": {
    "line": { "width": 2, "curve": "linear", "dots": false }
  }
}
```

Ключи совпадают с полями `Settings` в [`src/catalog.tsx`](src/catalog.tsx). Код обёртки с итоговыми свойствами для выбранного вида по-прежнему виден на вкладке «Пример кода». Тот же формат лаборатория хранит в `localStorage` под ключом `chart-lab:settings`. Если хранилище недоступно, настройки живут до перезагрузки страницы.

## Цвета дизайн-системы

Стенд подключает официальный CSS-модуль `@sddsjs/sdds_finai/css/sdds_finai_default.module.css` версии 0.2.1. Переключатель в шапке применяет класс `light` или `dark` к корню лаборатории. Адаптеры передают тему в `RechartsThemeProvider`. SVG-серии, подсветка категории, подсказка и поверхность читают CSS-переменные SDDS; у автономных примеров есть резервные значения. Голубой `data-blue` обозначает факт, жёлтый `data-yellow` — план. В светлой теме для контура плана используется более тёмный `inverse-data-yellow`. Роли поверхностей, границ и текста взяты из палитры таблицы. В панели «Палитра SDDS» рядом с каждым HEX видно имя CSS-токена. Для ручного значения указывается «Вручную». При различающихся цветах заливки и контура показываются оба токена. [Пакет атомарной команды](https://www.npmjs.com/package/@sddsjs/sdds_finai/v/0.2.1) · [Соответствие ролей](charts/theme.ts)

Тема экспортируется через `@chart-lab/charts/theme`. Этот ESM-вход содержит данные и импортирует только типы Recharts. При обновлении SDDS сверить оба набора значений с файлами `css/sdds_finai_default__light.css` и `css/sdds_finai_default__dark.css` новой версии. Для поверхностей и текста сверить ключи с `TABLE_STATE_COLORS` в TableGlide. После обновления повторить измерение и визуальную проверку обеих тем.

## Локальный запуск

Из каталога `charts-lab` с Node.js 22 и pnpm 10.30.3:

```sh
pnpm install --frozen-lockfile
pnpm dev
```

`pnpm build` компилирует ESM-входы и объявления TypeScript в `lib`, проверяет потребителя и собирает стенд в `dist`. При изменении исходников обёрток повторите `pnpm build:lib`. Относительные URL ассетов работают под путём репозитория на Pages.

### Тема приложения

```tsx
import atomic from '@sddsjs/sdds_finai/css/sdds_finai_default.module.css';
import { RechartsThemeProvider } from 'recharts';
import { chartThemes } from '@chart-lab/charts/theme';

function Theme({ mode, children }: React.PropsWithChildren<{ mode: 'light' | 'dark' }>) {
  return <div className={atomic[mode]}>
    <RechartsThemeProvider value={chartThemes[mode]}>{children}</RechartsThemeProvider>
  </div>;
}
```

Обёртки наследуют внешний контекст. При передаче собственного `chartTheme` конкретный график создаёт вложенный провайдер. CSS-модуль входит в сборку стенда; импорт обёртки в другое приложение сам по себе его не подключает.

## Импорт одного вида

```tsx
import { LineChart } from '@chart-lab/charts/line';
import { chartThemes } from '@chart-lab/charts/theme';

export function Revenue() {
  return <LineChart
    title="Продажи, млн ₽"
    data={[{ month: 'Янв', sales: 21 }, { month: 'Фев', sales: 28 }]}
    categoryKey="month"
    series={[{ key: 'sales', label: 'Продажи' }]}
    chartTheme={chartThemes.light}
    strokeWidth={3}
  />;
}
```

`@chart-lab/charts` — локальное имя приватного пакета прототипа. Десять подмаршрутов в `exports` ссылаются на независимо скомпилированные ESM-модули. Общее оформление лежит в `charts/shared.tsx`. Страница использует реальные подмаршруты и загружает выбранный вид через `React.lazy`. Реактивные настройки и данные принадлежат стенду. npm-публикация или изменение UI-кита для запуска не требуются.

## Проверка веса

`pnpm measure` собирает тринадцать минимальных потребителей через Vite 6.4.1 и обновляет [`src/sizes.json`](src/sizes.json). В контрольный пример входит React 18.3.1 с React DOM. Остальные используют тот же код монтирования и один или все подмаршруты графиков и карточки KPI вместе со светлой и тёмной палитрой DS. Скрипт проверяет список оставшихся адаптеров по отрендеренным модулям Rollup и записывает модули каталога Recharts `chart/`. gzip считается отдельно для каждого JS-чанка. Вкладка «Размер импорта» читает результаты.

Актуальные размеры в байтах записаны в `src/sizes.json` и показаны в разделе «Размер импорта» на стенде. При чтении прямого импорта одного графика в его сборку входит общая часть движка.
